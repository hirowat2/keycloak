2.4 · Depois da troca

  1. Espere o Keycloak voltar (1 a 2 minutos): o banco em uso acima deve mostrar os realms do dump e o migration_model igual ao conferido.
  2. No log, Failed to add user 'admin' … user with username exists é normal: o admin vem do dump, com a senha do ambiente antigo. Para trocar, use a seção 4.
  3. Se o dump veio de outro host, ajuste a Frontend URL e os redirect URIs na Migração da VM (passo 3).
